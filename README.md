# StationProject

A multi-layered C# project (DAL, BLL, UI) simulating a station management system.  
The project demonstrates clean architecture and separation of concerns between data access, business logic, and user interface layers.

## Features
- Data Access Layer (DAL) for handling database interactions.
- Business Logic Layer (BLL) implementing core logic.
- User Interface (UI) for interacting with the system.
- Demonstrates principles of OOP and clean code.

## Technologies
- C# (.NET Framework)
- Visual Studio
